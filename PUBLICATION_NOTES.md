# Publication copy notes

The publication bundle was prepared as a clean file distribution, without copying the original `.git` directory. It was then initialized and published as a separate repository, leaving the research repository intact. The original local history contains a committed archive above GitHub's regular-Git file limit; copying that `.git` history would reintroduce the blocker.

The selection keeps stable source/config/locks/fixture code, protocols/reports/claim summaries and small CSV/JSON/figure evidence at their historical relative paths. Some small source/table duplicates remain to preserve report and fixture references. Large archives/checkpoints/raw data, generated fixture attempt trees, caches, downloaded packages, private chat and operational/approval receipts are excluded. Active capacity-reader source/revision packages are excluded until separately completed and reviewed.

The public root README replaces the stale local operational README. No license was added because the publisher has not selected one. Personal-home redactions and broken-local-link annotations are mapped in `PUBLICATION_TRANSFORMATIONS.json`; missing references appear in `PUBLICATION_LINK_LIMITATIONS.json` and `PUBLICATION_DEPENDENCIES.json`.

Only static syntax/import/reference validation was done. This is not a newly executed reproduction. Installation, training, numerical audits and historical fixtures were not run. Credential-pattern checks are bounded heuristics and do not guarantee absence of secrets or all private information.

Markdown reports originally written in Indonesian or mixed-language prose have been translated into professional English in this publication copy. Measurements, uncertainty, negative and undefined findings, citations, commands, and archival status are preserved. These are public documentation derivatives; the original local documents and experiment-bound manifests remain unchanged. `PUBLICATION_MANIFEST.csv` records current publication-file hashes, while historical evidence hashes continue to describe their original source files.
